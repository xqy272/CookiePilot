RECOMMENDED / 在线更新

油猴版：安装一次，持续更新

  1. 浏览器安装 Tampermonkey 或兼容脚本管理器。
  2. 点击下面的稳定版安装链接，在管理器中确认安装。
  3. 刷新 Cookie Clicker，点击顶栏的 Pilot。
  4. 以后由脚本管理器检查更新，更新后刷新游戏生效。
安装稳定版 ↗

游戏自动操作默认关闭。油猴版隐藏广告版面；网络广告可使用已有拦截器。

LOCAL EXTENSION / 自带网络拦截

Chrome / Edge 本地扩展

  1. 解压本包，打开 chrome://extensions 或 edge://extensions。
  2. 开启开发者模式，选择「加载已解压的扩展程序」。
  3. 选择 extension 文件夹，然后刷新游戏。
  4. 更新时下载新包、替换文件、在扩展页重新加载。

本地扩展可以提示版本，但不能静默替换文件。商店版发布前保留此更新流程。不要与油猴版同时启用。

交互演示所有版本与更新记录 ↗

临时试用与旧版本升级

复制代码后，在游戏的 F12 → Console 中粘贴运行。若浏览器限制粘贴，请按浏览器提示自行处理，或选用脚本管理器。临时运行不会在刷新后自动加载。v1 设置会迁移，默认关闭自动操作；v1 存档快照仍保留在原键中，可从旧版导出。新版可同时导出存档和助手设置。
