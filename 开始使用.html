安装 Cookie Pilot

覆盖建筑与升级、花园、魔法、神灵、股市、龙与转生的中文助手。从游戏顶栏 Pilot 打开挂机总览、玩法规则和规划台。

脚本管理器

安装本包的油猴脚本

  1. 浏览器安装 Tampermonkey 或兼容脚本管理器。
  2. 在脚本管理器中导入本目录的 CookiePilot.user.js。已有同名版本时，确认替换。
  3. 刷新 Cookie Clicker，点击顶栏的 Pilot。
  4. 以后由管理器检查发布渠道的更新。升级后刷新游戏。
获取本包油猴脚本

游戏自动操作默认关闭。油猴版隐藏广告版面；网络广告可使用已有拦截器。

Chrome / Edge

Chrome / Edge 本地扩展

  1. 解压本包，打开 chrome://extensions 或 edge://extensions。
  2. 开启开发者模式，选择「加载已解压的扩展程序」。
  3. 选择 extension 文件夹，然后刷新游戏。
  4. 更新时下载新包、替换文件、在扩展页重新加载。

本地扩展可以提示版本，但不能静默替换文件。商店版发布前保留此更新流程。不要与油猴版同时启用。

临时试用与旧版本升级

复制代码后，在游戏的 F12 → Console 中粘贴运行。也可通过上方脚本管理器导入。临时运行不会在刷新后自动加载。v1 设置会迁移，默认关闭自动操作；v1 存档快照仍保留在原键中，可从旧版导出。新版可同时导出存档和助手设置。
