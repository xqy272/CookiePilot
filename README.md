# Cookie Pilot 3.1.0 · 饼干领航员

为 **Cookie Clicker 网页版 2.058** 制作的中文助手。点击游戏顶栏的 Pilot 打开约 600 像素宽的工作台。玩法规则直接进入分类、规则配置与实时状态。主题支持深绿、暖白和跟随系统。

[发布渠道](https://github.com/xqy272/CookiePilot/releases) · [更新记录](CHANGELOG.md) · [测试报告](验证报告.md)

## 安装与更新

### 推荐：油猴

在 Tampermonkey 或兼容脚本管理器中导入安装包里的 `CookiePilot.user.js`。如果已经装过 Cookie Pilot，确认替换已有条目。刷新游戏，点击顶栏 **Pilot**。脚本内置全部执行代码，发布渠道的更新由管理器检查，刷新游戏后生效。

助手设置页读取 GitHub 的版本清单，只有发现更新时才会显示升级入口。切换稳定／测试脚本渠道可从对应发布页重新安装。同一浏览器只需启用一种安装方式。

### 本地 Chrome / Edge 扩展

下载发行 ZIP，解压到固定位置。在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载 **extension** 文件夹，再刷新游戏。本地扩展另有声明式广告请求拦截。更新时下载新包、替换文件、在扩展页重新加载；普通本地扩展不能静默自动替换安装文件。商店发布并不包含在当前发行渠道内。

请只启用一种加载方式。重复运行同一新版会复用现有实例；新版会尝试清理旧版的运行实例。若旧版油猴脚本仍在管理器启用，建议关闭或删除旧脚本，避免下次页面加载顺序造成冲突。

### 临时运行

用浏览器打开 `开始使用.html`，复制临时代码，在游戏 F12 → Console 中运行。刷新后需重新运行。浏览器可能要求自行处理粘贴提示。当前保存目录内也有 `CookiePilot.user.js`，可以手动粘贴到脚本管理器。

## 工作台与场景

- **Alt + P**：打开或关闭工作台。**Alt + Shift + P**：暂停或恢复自动化。输入框中不触发快捷键。
- 工作台在桌面使用 600 × 480 像素。窗口不够大时按可用尺寸缩小，切页时保留面板尺寸和位置。长页只在内容区滚动。
- **总览**显示挂机时长、操作次数、实际点击、接下来两项动作及一条保护提示。顶部持续显示挂机状态。点击「查看队列」可看到其它能估时的动作和拦截原因。
- **玩法托管**从总览进入。可按玩法查看下一步，单独启停，或一次确认「启用全程挂机」。方案绑定当前存档。
- 总览显示预计执行、主要阻塞、最近成功操作和最近异常。最近成功操作和异常会保存在浏览器，刷新后可查看。
- **玩法规则**首次打开花园，之后保留本次会话的模块与规则选择。上方选玩法和具体规则，下方配置左栏、查看右栏的实时状态。
- 首次所有自动化关闭，广告版面隐藏开启。默认刷新后等待手动恢复，规则设置保留。可开启刷新恢复，手动暂停跨刷新保留。
- **日常挂机**：连点、金饼干、驯鹿、幸运新闻、安全成熟糖块和采购。应用前展示将变更的规则与库存保留策略。
- **主动爆发**：只在点击增益时连点，拾取金饼干和驯鹿，点击爆发时暂停采购和交易。
- **花园培育**：只收取成熟的未解锁种子。补种布局由用户另行配置。
- **仅看信息**：关闭全部自动化，继续提供信息、规划、存档与去广告。

### 自动转生

从「规划台 → 转生目标」检查本轮新增声望、成套升级价格、前置和按无增益产量估算的等待时间。路线从 390 筹码的首转基础开始，接着解锁季节、更多永久栏和后续增长升级。账上剩余筹码可以用于下一套。后期如果下一套所需新增声望远高于当前声望，路线会先转一轮抬高永久加成并保留筹码。

达标后保存转生前重点快照，再用扣除库存保留量后余额的 1% 统一预算补齐临近建筑成就，结算普通皱纹虫。规划台会显示本轮可补的成就和费用上限。魔法书托管、金饼干拾取和连点都开启时，如果下一发命运之手预测为点击狂热，脚本会留魔力等待自然金饼干带来的生产狂热。等待最多一次，默认 240 秒，可在转生托管中关闭。已叠加的点击爆发结束后转生。之后在天堂按前置顺序购买，为可用永久栏选择本轮已买的小猫升级，再进入正常轮回。已有的非小猫槽位配置会保留。挑战和闪光皱纹虫保护仍然生效。浏览器刷新后，脚本会用游戏当前的轮次、筹码和升级状态接续任务。自动转生需要浏览器的 Web Locks 执行锁，手动准备转生和达标提醒也可单独使用。

## 模型和边界

### 采购估算

候选分数为等待购买时间加回本时间。模型读取实际单栋产量、全局倍率、层级、协同、奶猫、手指升级、点击升级和部分数量成就；预测过程不修改真实建筑、升级、成就或游戏随机状态。结果是**更完整的估算，不是所有机制和 Mod 的精确模拟**。部分事件型升级不适合用 CpS 衡量，可以指定为目标。无法建模的升级仍展示，但不会自动购买。

One mind、研究、Chocolate egg、开关类、糖块消费、天堂升级、保险库及有自定义交互的升级单独处理。普通自动采购不买这些。手动购买会调用游戏原始方法，并保留游戏自己的确认。

Lucky 保留线为当前 CpS × 6000；狂热保留线为 `max(当前 CpS, 无临时增益 CpS × 7) × 6000`。采购还使用估算的买后产量核对保留线。可选的过渡购买只在预计缩短主目标等待时执行。购买等待按当前被动产速估算，并随产速和预算变化重算。挑战和库存保护作用于助手的规则。

### 糖块与解锁

在「规划台 → 糖块与解锁」查看安全收取与自然掉落倒计时，或开启完全成熟后收取。路线按钮可对比四个小游戏的解锁成本、花园扩至 6×6 的成本及下一档股市办公室的光标等级要求。可以为任意建筑填写等级目标，查看下一级开销、达到目标的总成本及预计等候时间。等待按当前生长速度和每轮收取 1 颗估算。

「持续托管」确认一次就会收取成熟糖块，依次解锁已拥有建筑的小游戏。默认「解锁与成长」还会把农场逐级升至 9 级，再达到当前股市办公室的光标等级门槛及已买手套的等级上限。也可以选择「只解锁小游戏」。可花预算不足时等待，路线达标后继续收取和储存，托管花费限于建筑等级。停止托管后可沿用独立收取规则。

建议优先解锁已持有建筑的小游戏。开启了对应挂机规则时，相关小游戏优先。其他情况下推荐万神殿、花园、魔法书、股市，随后按玩法给出花园扩建、办公室、手套或建筑增产建议。花园在农场 9 级达到 6×6。建议需要玩家点选和确认才会执行。

「按存档推荐」在取得 Sugar baking 之前保留 0 颗。取得后，每颗未花的糖块增加 1% 产量，上限 100 颗。常规等级目标默认留足 100 颗，仍可单独用 1 颗解锁小游戏。想提前分配或预留更多时可选择「自定保留量」。升级时，已启用的旧目标及之前设置的非默认保留量沿用原数值。

点击「安排此建筑升级」可预览执行范围、开销、保留量和结束条件。确认后，Pilot 在当前存档中逐级执行，每次先备份并重新核对保留量，达标时结束任务。手动升级遵循游戏自己的糖块确认选项。可在「玩法规则 → 采购与糖块 → 糖块升级」暂停。同一时间执行一个建筑等级目标，糖块收取由独立开关控制。

### 花园

生长和枯萎时间是平均估算，突变展示是当前邻居条件下的基础每次尝试概率。土壤、随机成长等会影响实际结果。保护格阻止助手操作，自然生长和枯萎仍由游戏决定。花园托管按实际地块匹配至多两种亲本的突变条件。需要更多地块或足够的亲本同时成熟时，面板会显示等待状态。手动「补种布局」仍可配置固定亲本并预留隔行空位。

「育种、收藏与收益」会在生长期选择肥料，亲本成熟后可切换木屑。换土遵守原版冷却，花园有保护格时保持当前土壤。种子收齐后种植能掉落升级的作物并购买已解锁的奖励，随后用预期净产量挑选收益作物。可指定作物和收获倍率。临近枯萎时会提前收获。

### 魔法与组合

命运之手预测使用独立的字符串种子随机流，**不替换或推进游戏 Math.random**。结果以当前季节、金饼干数量、建筑数量、Dragonflight 和原版法术逻辑为条件；其他施法改变序号后重新计算。后续预测假设这些条件维持不变。改变法术的其他 Mod 不受保证。自动施法不选择 Gambler's fever dream，避免延迟随机子法术破坏可预测的预算。

Godzamok 必须先装备、明确选择出售建筑，并留足保守回购成本。出售前按存档和轮次记录回购目标。若刷新或暂时缺预算，Pilot 会按实际建筑数量接续恢复，待回购期间优先保留饼干。每个点击增益只执行一轮出售。不要同时运行其他自动购买、出售或施法助手。

万神殿的「神灵调换」可预览适合被动挂机、持续连点或加快糖块成熟的阵容。「按当前挂机规则」在持续连点开启时优先点击，否则优先建筑产量。奶猫与建筑总数会影响选出的神灵。应用阵容会维持指定槽位，消耗原版调换次数并保留设定额度，未用的槽位可自行配置。

### 股市

分位基于本机采集的最近最多 2000 个市场 tick，并非 Insugar Trading 的长期模拟数据，也不保证获利。银行等级、龙光环或本轮开始时间变化会清空样本。达到最低样本数才使用分位策略；指定固定买卖线则无需等待样本。

自动交易仅对空仓商品开仓，记录包含手续费的单位成本，达到目标卖价和最低净利润后出售。手动交易造成数量变化后会废弃该仓位的助手成本。成本未知的仓位由玩家管理。银行或龙光环变化后重新采集样本，同一轮已记录的仓位成本继续有效。

「发展与交易」会在满足光标等级和库存后调用原版办公室升级，消耗该级所需指针并遵守已设保留量。按预算雇经纪人时也遵守原版数量上限。已达净利目标的卖单优先于发展支出。转生爆发贷款默认关闭，可对当前存档批准一种。只在计划转生的点击狂热组合已触发、库存在扣除后符合保留线，且预计额外收益能覆盖首付时使用。每轮至多一次。若中途暂停太久而没有转生，原版减产期照常生效。

### 运行与存档

只针对网页 2.058 开启自动化。未知版本保留只读信息，自动操作暂停。后台可能降频或被冻结，休眠或关页不会继续运行；不追赶积压点击。多标签自动化使用 Web Locks 协调，旧浏览器缺少此 API 时不保证跨标签互斥。游戏自身多标签存档竞争不由助手解决。

本地存储键为 `cookie-pilot:settings:v2`、`cookie-pilot:backups:v2`、`cookie-pilot:market:v2`，与游戏存档分开。旧版 v1 键仍保留。清除站点数据会清掉助手设置与备份，请下载长期存档。恢复快照回退之后进度；实验室资源补给会影响游戏产量、成就和转生。设置与备份不会被上传；检查更新只向发布地址读取静态 JSON，不附带存档。

## 开发与发布

Node.js 20+，构建和基础测试没有第三方依赖。

```sh
npm run build
npm run check
npm test
npm run serve
```

`src/core.js` 为纯分析模型，`src/management.js` 为托管决策，`src/engine.js` 为规则和存储，`src/app.js` 为工作台与生命周期，`src/styles.css` 为样式。构建生成扩展、油猴、更新元数据和安装入口。

独立演示：打开 `界面预览.html` 或本机预览 URL，可在前期／后期模拟存档中运行交互测试。测试不使用你的真实游戏存档。

官方对照验证：运行 `node tools/fetch-reference.mjs` 下载当前官方脚本到 `.cache/reference`，设置环境变量 `COOKIE_PILOT_REFERENCE_DIR` 为该绝对目录，再执行 `node --test tests/official.test.cjs`。这些官方文件不进入仓库或发行 ZIP。网络站点可能拒绝下载；应使用已核对版本的官方参考脚本。

发布：修改源码版本和 package.json → 测试 → 构建 → 提交生成的 `dist` 文件到 main → 推送 `vX.Y.Z` 标签。CI 验证构建一致性，release 工作流验证标签版本后发布 ZIP 和油猴附件。稳定更新源固定为 main/dist/stable；测试版为 beta。发布前先检查 CHANGELOG 和兼容列表，不在自动运行时热替换代码。
